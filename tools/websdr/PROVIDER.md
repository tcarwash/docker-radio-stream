# Provider evidence and boundaries

Static operator pages/scripts retrieved during this implementation (no receiver browser/audio session was opened):

- https://www.sdrutah.org/ links `http://websdr1.sdrutah.org:8901/index1a.html` for 2200/630/160/80/60/40m and `http://websdr2.sdrutah.org:8902/index1a.html` for 30/20/17/15/12/10m (plus bottom 1 MHz of 6m, outside our HF validation). The map deliberately uses selected amateur-band subsets, not continuous 0–30 MHz coverage or a claim about capacity/antenna direction. WebSDR 3 is not automatic failover.
- http://websdr1.sdrutah.org:8901/tmp/bandinfo.js publishes centers/sample rates in kHz: 1900/384 (160m), 3750/768 (80m), 5200/768 (60m), 7125/768 (40m), among others. These cover our server-1 subsets. Server-2 band labels are verified from the operator landing page; exact instantaneous server-2 band edges/capacity have not been probed.
- http://websdr1.sdrutah.org:8901/websdr-base.js: `setfreqb(f)` auto-selects a band and calls `setfreq`; band changes can flip USB/LSB. `setmf(m,l,h)` assigns uppercase `mode`, `lo=l`, `hi=h`, calls `updbw()` and sends sound settings. `set_mode` defaults demonstrate filter units (`setmf("usb",0.15,2.86)`, `setmf("am",-4,4)`): these are **kHz**, not Hz. Therefore the bridge applies frequency first, then explicit mode/filter converted from Hz, and validates `freq/mode/lo/hi` readback. `chrome_audio_start()` and `mozilla_audio_start()` are actual click handlers in this script.
- http://websdr1.sdrutah.org:8901/websdr-soundhooks.js defines `hook_webaud(sample, sampleRate, ...)` and returns the processed scalar sample. The bridge preserves a scalar hook before provider scripts load, batches it and resamples to 8 kHz PCM. The offline fixture exercises that contract; it does not reproduce real RF transport.
- https://www.sdrutah.org/info/about.html prohibits permanent connections defeating timeouts without permission. https://www.sdrutah.org/info/kiwifaq.html asks amateurs to use conventional WebSDRs on supported bands. The existing 25-minute/90-minute local guard is conservative and shared across source types, not a statement that Kiwi limits are WebSDR limits. No automatic reconnect or failover is implemented.

Use the operator-linked **HTTP + explicit port** URL. A probe to `https://websdr1.sdrutah.org/` failed certificate hostname validation; TLS verification was not disabled. HTTP is unencrypted; do not put credentials in receiver URLs. No public live receive/broadcast validation was performed. Re-check provider contracts and permission if scripts/terms change.
